Wat is GitHub?

Git is een systeem waarmee je de geschiedenis van je code kunt bijhouden. Je kunt wijzigingen opslaan in zogenaamde commits.

GitHub is een online platform waarop Git-projecten kunnen worden opgeslagen en waarop developers kunnen samenwerken.

🐙 Git + GitHub

Git zorgt voor versiebeheer. GitHub maakt het eenvoudig om projecten online te delen en samen eraan te werken.
